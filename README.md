# Janad University — Website

A modern, fully responsive website for **Al Janad University for Science and Technology** (Taiz, Yemen). Originally built as a university project, now fully refactored into a professional, production-ready website.

## ✨ Features

- 🎨 **Modern design** — clean UI, soft shadows, gradient accents
- 📱 **Fully responsive** — optimized for mobile, tablet, and desktop
- ⚡ **Performance-first** — lazy-loaded images, minimal JS, no frameworks
- ♿ **Accessible** — semantic HTML, ARIA labels, keyboard-friendly
- 🌙 **Smart sticky navbar** — transparent → solid on scroll
- 🍔 **Mobile drawer menu** with backdrop
- 🎯 **Active link highlighting** based on current page
- ✨ **Scroll reveal animations** via IntersectionObserver
- 🔢 **Animated counters** (statistics)
- ✅ **Client-side form validation** — with inline error messages
- 🧭 **Scroll-to-top button**
- 🚫 **Custom 404 page**
- 🔍 **SEO-ready** — meta tags, Open Graph, favicon
