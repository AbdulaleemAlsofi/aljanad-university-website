# Aljanad University Website

## Project Overview

An individual academic project developed as part of the Web Design course during the second level of the Information Technology program at Aljanad University for Science and Technology.

The project demonstrates the practical application of fundamental web design and development concepts through the creation of an informational university website, focusing on content organization, visual styling, and responsive design.

## Key Features

- Informational website introducing Aljanad University for Science and Technology.
- Organized website pages and content sections.
- Structured content and visual elements for improved readability.
- Responsive design compatible with desktop computers, tablets, and smartphones.
- Practical implementation of fundamental web design and development concepts.

## My Role

Developed the project individually, taking responsibility for designing the website pages, writing the source code, organizing content, styling visual elements, and implementing a responsive user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
